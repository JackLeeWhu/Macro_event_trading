# Aggregate research results

- [performance_summary.csv](performance_summary.csv): reported full-sample metrics and cumulative return. Rates are decimal fractions; ratios are unitless.
- [calendar_returns.csv](calendar_returns.csv): returns compounded within each calendar year. The 2026 row ends on September 9 and is not a full-year or annualized return.

These are outputs from an exploratory gross historical backtest, not live performance. See [assumptions and interpretation](../docs/results.md). Only aggregate results are shared here.
